# AIOps Agent 开机自启说明

## 一、Linux（systemd，适用于 CentOS 7+/openEuler/Rocky/Ubuntu 16+/龙蜥）

1. 将 Agent 部署到 `/opt/aiops-agent`（含 `agent.py`、`collectors/`、`config.yaml`）。
2. 安装依赖：
   ```bash
   pip3 install -r requirements.txt
   ```
3. 复制并启用服务：
   ```bash
   cp /opt/aiops-agent/systemd/aiops-agent.service /etc/systemd/system/
   systemctl daemon-reload
   systemctl enable aiops-agent    # 开机自启
   systemctl start aiops-agent     # 立即启动
   systemctl status aiops-agent    # 查看状态
   journalctl -u aiops-agent -f    # 查看日志
   ```
   注意：若 Python 不在 `/usr/bin/python3`，请先用 `which python3` 确认并修改单元文件中的 `ExecStart` 路径。

## 二、Linux（无 systemd 的旧系统，如 CentOS 6）

在 `/etc/rc.local` 末尾追加（后台运行）：
```bash
cd /opt/aiops-agent && nohup python3 agent.py >> /var/log/aiops-agent.log 2>&1 &
```

## 三、Windows（2008 ~ 2019）

### 方式一：注册为 Windows 服务（推荐，使用 NSSM）

1. 下载 NSSM（https://nssm.cc/），解压后以管理员身份执行：
   ```bat
   nssm install AiopsAgent "C:\Python38\python.exe" "C:\aiops-agent\agent.py"
   nssm set AiopsAgent AppDirectory "C:\aiops-agent"
   nssm set AiopsAgent Start SERVICE_AUTO_START
   nssm start AiopsAgent
   ```
2. 卸载服务：`nssm remove AiopsAgent confirm`

### 方式二：任务计划程序（无需第三方工具）

以管理员身份执行：
```bat
schtasks /Create /TN "AiopsAgent" /TR "C:\Python38\python.exe C:\aiops-agent\agent.py" /SC ONSTART /RU SYSTEM /RL HIGHEST
```
删除任务：`schtasks /Delete /TN "AiopsAgent" /F`

### 注意事项

- Windows Server 2008/2008R2 请安装 Python 3.8（官方支持该系统的最后版本）。
- 建议以管理员权限运行，否则监听端口与进程的对应关系可能无法获取。
- `config.yaml` 中的 `url`、`token` 需与服务端保持一致，修改后重启服务生效。
